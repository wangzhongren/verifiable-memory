# 本地配置与真实模型解析修复

2026-09-22；代码基线 `a66468c2709d8dd4ac7b0d37ca31448518b5e963`。

## 问题与行为变化

1. 原提示词要求所有事实写成“方向是X”，真实模型因此把分支名 `main` 存成“方向是main”。现在一般事实保留用户声明的值；只有事实本身描述方向时才用方向表达，并保留“向上”“朝右”等原词。名称、版本、数字和单位不自动改写成其他类别。
2. `paraphrases` 把操作字典错误解包为 `op, source`，三字段操作报错、两字段查询变成字符串。现在直接接收字典，保留严格相等判定；错误、原始结果和各例前置状态均写入可选结果文件。
3. 原改写基准给所有用例同一组已知槽位，导致“教学实体07”的期望与实体07已存在的状态矛盾。基准标为 `paraphrases@v2`，每例明确前置状态；原话和期望操作保持不变，未改用模糊评分。旧 `PROTOCOL.md` 保留为历史预声明，旧测量结果不改写成新结果。
4. 模型配置可保存在用户目录 `~/.config/verifiable-memory/config.json`，无需环境变量或独立测试脚本。CLI 优先用本地文法；口语在本地配置存在时自动调用模型。`--llm` 强制模型解析，`--no-llm` 禁止模型调用，`--config` 指定其他文件。本地配置不完整时明确报错，不静默混用环境中的另一把密钥。
5. 原生支持 OpenAI Chat Completions 与 Anthropic Messages，包括代理路径前缀、Bearer token、API key、文本内容块。HTTP 错误中的认证值被遮蔽，缺失/非文本响应报错，不转成可写入的事实。

本地配置只保存在本机；仓库、测试用例和 CI 中不包含实际密钥。环境变量入口保留兼容性，但不是本机使用的必需步骤。
