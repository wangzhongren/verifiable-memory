# PROTOCOL — verifiable_memory_01（预声明，执行前冻结）

日期：2026-09-21 · 状态：**冻结**（本文件在 `cli.py script` 执行前被快照进 `demo/frozen/`，此后不得修改；期望答案在冻结时即已确定）

## 一、定位与假设（预声明）

**假设**：八轮实验确立"显式寻址赢、学习型软寻址输"之后，下一个可交付物不是更大的 LM，而是**组装一个可验证的可教学记忆系统**：自然语言在验证边界上游由真实 LLM 解析为结构化操作，边界内只有确定性代码（命名槽位 + 符号执行器），因此每个答案都能附带证据链，每次纠错都能证明零附带损害，整个会话能在独立进程逐位重放。

**差异化主张**：不在性能（执行器是符号的，100% 正确是平凡事实），在**可验证性**——LLM 可以答错，但错误要么在解析层被词表白名单拦截，要么如实留痕在 op 日志里；核心状态永远可独立重建。

## 二、v1 范围（用户确认的三项决定）

1. 解析层：OpenAI 兼容接口（`VM_BASE_URL/VM_API_KEY/VM_MODEL`）；无 key 时结构化命令后备文法可跑通全部固定场景；
2. 执行器：仅符号后端（v1 纯组装不训练；神经检查点接入为第二阶段）；
3. 零第三方依赖，纯 Python 标准库。

## 四、验收标准（8 条，全部可机器检查）

1. **固定场景**：`cli.py script` 依表三执行 18 步，解析结果逐条等于预声明 op，答案逐条等于预声明答案；
2. **灵魂样例**：#9 → 3214、#17 → 1432，且 verify.py 独立断言两者之间隔着一次成功更正；
3. **零附带损害**：每次纠错（#13、#14）后其余全部槽位哈希逐位不变，由证书（写前/写后逐槽哈希表）证明，并经 verify.py 独立重算比对；
4. **跨进程**：teach（进程1）→ ask（进程2）→ correct（进程3）→ ask（进程4），答案保持且正确（checks.py 以真子进程覆盖）；
5. **独立重放**：replay.py 新进程只读 op 日志逐条重放（写证书逐字一致、读结果逐字一致、错误逐字一致）；verify.py 再以第二套原语实现独立重算全部答案与终态哈希，全部吻合；
6. **无 key 后备**：固定场景全程用后备文法完成（场景三的语法即后备文法）；
7. **LLM 解析鲁棒性**：预声明 10 条同义改写（data.PARAPHRASES）经 LLM 解析为期望 op 的比例如实报告（目标 ≥9/10；失败如实记录，不调参重试）；
8. **惯例**：PROTOCOL 先冻结后执行；demo/ 拒绝覆盖；manifest 记录全部源码 sha256。

## 五、失败语义

- 解析失败、op 校验失败、存在性/容量/种类错误：显式报错并落日志（错误条目无副作用、哈希链不断）；
- 执行器对非法输入/未知原语抛错，宿主不得代为修复；
- verify.py 任何一处不符即整体失败退出码 1。
